# AntennaKey

AntennaKey enables high-gain, adaptive signal reception across multiple protocols, empowering real-time system control and efficient data transmission.

AntennaKey is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/AntennaKey.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure AntennaKey, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
